# ADR 0001: границы первого каркаса

Статус: принято для Slice 0, 2026-10-29.

Это новый редактор производственных таймлайнов. Исходной игры в этом репозитории нет. ARCHITECTURE.md и CODEX_SPEC.md описывают конечную архитектуру; текущая задача ограничена Slice 0 и схемами Slice 1.

## Границы модулей

- `domain`: календарные функции, UUID, runtime-схемы Zod и выводимые из них readonly-типы; без React, хранилища, сети и побочных эффектов.
- `application`: интерфейс `ProjectRepository` и чистые запросы для представления.
- `infrastructure/demo`: неизменяемая фиксированная фикстура, проверяемая той же схемой, что и будущие документы.
- `features/projects`: обзор и сводка только для чтения. Получают данные через props, не импортируют адаптеры.
- `app` и `main.tsx`: композиция, состояния экранов, подключение фикстуры. Ограничения направления импортов закреплены ESLint.
- `styles`: токены и стили оболочки.

Директории остальных features появляются с соответствующими срезами, а не как пустые реализации.

## Демо и навигация

Начальный экран — пустой обзор проектов. Кнопка явно включает один демонстрационный проект. Фиксированные UUID/даты/время исключают зависимость от часов устройства, randomUUID и порядка генерации. Сводка показывает процессы, задачи и датированные этапы списками, без временной оси и редакторских действий. Сброс страницы снова показывает пустой обзор; это демонстрация без сохранения, а не потеря пользовательских данных.

Два экрана переключаются типизированным состоянием React; маршрутизатор, deep links и кнопка Back браузера пока не являются контрактом. Пока нет сложного временного состояния редактора, Zustand не нужен. Нет кнопок несуществующих операций, процентного прогресса или экранов настройки внешних сервисов.

## Контракт хранения

`ProjectRepository` — порт без адаптера, кеша или фиктивного sync-статуса. Описан атомарный save/delete с ожидаемой ревизией; создание использует `expectedRevision: null`. Проверку конфликтов и операции выполнят будущие команды/адаптер, сейчас они не реализованы. `schemaVersion: 1` — версия DTO, а не утверждение о наличии миграций IndexedDB.

Глобальные люди представлены отдельной коллекцией в документе демо. При реализации IndexedDB потребуется отдельная глобальная таблица людей; экспорт/импорт проекта должен явно обрабатывать ссылки на неё. Политика объединения одинаковых людей и конфликтов общей карточки остаётся открытой.

Нет CommandBus, undo/redo, Dexie, CRUD проектов, JSON import/export, фонового сохранения, временной оси, drag/resize, PDF или портфолио. Эти функции не заменяются заглушками.

## Проверки и инструменты

Node 24.19.0, npm lockfile; TypeScript 5.9.3 выбран в поддерживаемом диапазоне typescript-eslint. Vite/React, strict typecheck, типизированные правила ESLint, Vitest и Playwright Chromium. Тесты типов включены в `tsc -b`, а не только в транспиляцию Vitest. Browser-код не получает глобальные типы Node; тесты проверяются отдельным tsconfig.

Playwright проверяет production build через `vite preview`. По умолчанию используется Chromium соответствующей версии Playwright. Для этой облачной среды разрешён явный путь к установленному `/usr/bin/chromium` через `PLAYWRIGHT_CHROMIUM_EXECUTABLE_PATH`; пользовательскому приложению эта переменная не нужна. CI устанавливает браузер Playwright. Firefox/WebKit пока не проверяются.
