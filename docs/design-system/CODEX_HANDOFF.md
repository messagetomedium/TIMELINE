# Codex handoff — будущий редизайн PLINE по Figma/PNG v3.1

**Запускать только по отдельному явному заданию владельца.** Прочитать `AGENTS.md`, `docs/design-system/README.md`, `docs/design-system/DESIGN_SYSTEM_PLINE_V3.md`, `docs/design-system/FIGMA_LAYOUT_MAP.md` и адресные функциональные контракты из `docs/TIMELINE_MASTER_PLAN.md`.

Оригинал: https://www.figma.com/design/ZL9Fl89wbkuSpSAuqETPHr/TIMELINE---UIforGPT?node-id=0-1

**Важнее всего:** композиция владельца. Если в новом референсе элемент переехал — **перенести его**. Не ограничиваться изменением темы старых React-элементов. Макеты черновые по интервалам: исправить неровные края и повторные отступы единой системой, но сохранить относительные позиции, силуэт, иерархию и пустое пространство.

## Конкретные четыре экрана
1. **Frame 2 / 22025:6 — старт:** огромный PLINE слева, синяя папка справа, под ней чёрная ВОЙТИ и белая регистрация *вертикально*. Почти пустой белый фон.
2. **ЭКРАН ВХОДА / 22026:24:** крупный PLINE сверху, папочная рамка посередине, белая шапка, голубые email/password inputs, forgot-password справа под ними, синяя регистрация **снаружи снизу справа**. На референсе не нарисован submit Войти — **не удалять функцию**; поместить в свободную нижнюю зону рамки как временное дополнение и обозначить это в PR.
3. **ВСЕ ПРОЕКТЫ / 22026:66:** единый белый папочный корпус, home/активный workspace tab слева, архив/люди/выйти и wordmark справа, заголовок ВСЕ ПРОЕКТЫ слева, переключатель вида **сразу справа от заголовка**, первый элемент сетки — папка НОВЫЙ ПРОЕКТ, далее папки существующих проектов. **Без старого левого sidebar**.
4. **Frame 1 (10) / 14001:16 — редактор:** Дом + Проект tab сверху слева, ghost PLINE справа, большой единый контур, основная сцена ≈75% слева и отдельный светло-серый инспектор ≈25% справа, этапы сверху, процессы посередине, люди в нижней временной области, toolbar плавает снизу основной сцены, actions инспектора — в его нижней зоне.

## Новые цвета и характер
Белый `#FFFFFF`, чёрный `#000000`, голубая папка `#6089DB`, голубые поля `#6A93E3`, голубая задача `#91CFF5`, бледный голубой процесс `#CFECFE`, розовая работа `#EAB2CB`, правый инспектор `#F2F2F2`. Цвета — образцы из PNG, **не официальные Figma Tokens**. Не брать старые Klein Blue `#002FA7`, electric `#2457FF`, оранжевый `#FF6A00`, зерно, световые градиенты и прежнюю сетку v2. Чёрный тонкий контур и формы папок важнее декоративных эффектов. Font-family из PNG неизвестен; проверить в Figma/получить подтверждение, не угадывать.

## Перед реализацией
- Сопоставить каждый экран и переехавший элемент с существующим React-компонентом, **сначала layout, потом tokens/декор**, сохранить все действия и состояние.
- Проверить исходные изображения (Figma или экспорт) по возможности. Если они недоступны, `FIGMA_LAYOUT_MAP.md` и измеренные описание/цвета — проверенная основа композиции. Не утверждать пиксельного сходства без визуальной проверки.
- Ненарисованные действия (Войти submit, подтверждение email, создание, результаты, архив, guest, люди, Undo/Redo) не удалять; вписывать в новую систему без новой продуктовой логики.
- Сохранять server/local isolation, user-specific zoom/grid/weekends/pan/expanded view, даты, SegmentedAxis, каскады, транзакции, права, взаимодействия мыши/трекпада/клавиатуры.

## Выпуск
Новая feature branch, адресные lint/build/behavior tests, один PR, protected main `checks`, GitHub Pages для визуальной проверки владельца. **Не деплоить mediume.ru**, не менять SQL/Gmail/S3/DNS. Редизайн войдёт в будущий общий release candidate после остальных разрешённых версий.

Краткий отчёт Codex: какие UI-блоки перемещены, какие узлы/состояния не нарисованы, подтверждённость шрифта, token list, PR/SHA/checks и рекомендации по визуальной приёмке.
