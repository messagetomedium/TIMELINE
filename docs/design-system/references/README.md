# TIMELINE — карта референсов

Эти пять изображений были переданы пользователем как окончательно выбранные ориентиры для утверждённого визуального направления. Хранить их рядом с DESIGN_SYSTEM_V2.md; по отдельности не трактовать как технические требования.

## 01. TIMELINE / композиционный макет
Файл: **01-timeline-concept.webp**. Визуальная композиция открытого проекта: слева круглая «Домой», сверху язычки папок, крупный заголовок, календарная сетка, полосы, результаты, справа параметры. Он нужен для **композиции**, а не для изобретения новых сущностей. Нельзя перенести выдуманные проценты выполнения или смешать результаты с календарными днями. Точная актуальная логика находится в мастер-плане и коде.

## 02. Digital document / кибердокумент
Файл: **02-digital-document.webp**. Перекрывающиеся цифровые листы, выразительные закладки, условные машинописные подписи, неожиданные края, контрастное обрамление. Взять логику графических слоёв и микромаркировки **дозированно**. НЕ копировать фиолетовый и кислотный жёлтый.

## 03. Strelka / швейцарско-редакционная сетка
Файл: **03-strelka-typographic-grid.webp**. Особенно важны модульная верстка, мощный черный текст, сверхтонкие линии, разделение на смысловые поля, мини-подписи, плотные и свободные типографические зоны. Не копировать розовый фон или реальную идентичность мероприятия.

## 04. Folder window / окно с язычками
Файл: **04-folder-window.webp**. Силуэт папки, переход выступающих закладок в единый контур, изящная скруглённая поверхность, почти плакатная простота. Не добавлять в TIMELINE ретро-игровые значки и не менять иерархию навигации: круглая «Домой» остаётся **слева**.

## 05. Editorial / PORTFOLIO
Файл: **05-portfolio-editorial.webp**. Огромная гротескная типографика, сильное белое поле, атмосферный оранжево-синий цифровой градиент, видимый мелкий grain и контраст плотного/пустого. Использовать в главном экране и крупных hero-композициях. Не переносить огромные заголовки на каждую календарную строку.

## Приоритет

Прямые указания пользователя → функциональный TIMELINE_MASTER_PLAN → DESIGN_SYSTEM_V2.md → композиция референсов. Не восстанавливать старую пастельно-фиолетовую дизайн-идею из исторических макетов.

## Права и использование

Изображения загружены пользователем для визуальных ориентиров. Авторство и лицензии оригинальных сторонних работ здесь не подтверждены. Репозиторий публичный: эти файлы видны другим пользователям GitHub. **Не использовать сами референсы как графические ассеты готового продукта или маркетинговые материалы** без отдельного разрешения и проверки прав. Не предполагать, что загрузка в этот репозиторий передаёт права на сторонние работы.

Файлы представляют собой качественно оптимизированные копии пользовательских изображений (WebP вместо PNG), без изменения композиции и соотношения сторон.
