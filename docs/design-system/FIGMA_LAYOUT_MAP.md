## Общие правила

1. Макеты — предписание о позициях. Если элемент переехал — перенести его, а не только изменить цвет.
2. Черновые неровности исправить равными отступами/линиями и согласованной сеткой; относительные пропорции, иерархию, соседство сохранить.
3. Использовать CSS grid/flex и responsive, не абсолютные пиксельные координаты из PNG.
4. Цветовые токены и typography описаны в DESIGN_SYSTEM_PLINE_V3.md; точное семейство шрифта из PNG не определено.
5. Визуальные настройки участника локальные. Не создают серверных команд и не меняют другого пользователя.
6. Перенос React UI не изменяет auth, server-mode, timeline geometry, undo/redo, stages, checkpoints, dates, people и права доступа.
7. Этот документ — спецификация будущего редизайна, а не разрешение на обновление production VPS.
