# ПЛАЙН / PLINE — авторская дизайн-система v3.1

**Новый источник визуальной правды:** четыре PNG-макета, переданные владельцем 06.11.2026, и [оригинальный файл Figma](https://www.figma.com/design/ZL9Fl89wbkuSpSAuqETPHr/TIMELINE---UIforGPT?node-id=0-1).

**Прямое указание владельца:** если элемент интерфейса в макете расположен иначе, чем в текущем TIMELINE, его **надо переместить**. Макет задаёт композицию, порядок/иерархию и расположение, а не только стиль. Кривые интервалы черновика нужно выровнять, но не менять саму композицию.

2. **[FIGMA_LAYOUT_MAP.md](FIGMA_LAYOUT_MAP.md)** — детальная карта местонахождения основных элементов четырёх экранов и правил переноса относительно прежнего приложения.

5. **[../TIMELINE_MASTER_PLAN.md](../TIMELINE_MASTER_PLAN.md)** и корневой **[AGENTS.md](../../AGENTS.md)** — функциональное поведение, сервер, права, данные, релизы.

## Что устарело
`DESIGN_SYSTEM_V2.md` и `references/*.webp` — история старой концепции TIMELINE, **не активная дизайн-система**. Не брать оттуда Klein Blue, ярко-оранжевый, градиенты/glow, старые позиции элементов и старые пожелания по расположению кнопок. Новые PNG показывают иную композицию и иную палитру.

**Важно:** документация не даёт разрешения автоматически запускать редизайн или обновлять `mediume.ru`. Работа Codex — отдельно, после текущих функциональных заданий; выпуск на VPS только общим релизом после backup/restore и одобрения владельца.
